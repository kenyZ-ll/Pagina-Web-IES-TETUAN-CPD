## 🖼️ Vista Previa y Estructura

El sitio web está compuesto por tres páginas principales interconectadas:

1. **Home / Presentación (`Pagina01`)**:
   - Bienvenida y presentación personal.
   - Concepto y diseño del logotipo personal (*Shadow Windmill Shuriken*).
2. **Información del Centro (`Pagina02`)**:
   - Detalles sobre el **IES Tetuán de las Victorias** (ubicación, instalaciones, Erasmus+, servicios al alumnado y transporte).
3. **¿Qué he aprendido? / Portafolio (`Pagina03`)**:
   - Trayectoria académica (SMR & DAW).
   - Certificaciones obtenidas.
   - Proyectos de GitHub y stack tecnológico.

## 🎨 Guía de Estilos de la Marca

El diseño se desarrolló siguiendo un sistema visual definido en la Fase 1 con Figma:

### 🎨 Paleta de Colores
| Uso | Color Hexadecimal | Muestra |
| :--- | :--- | :---: |
| **Color de Énfasis** | `#0095FF` | 🟦 |
| **Textos y Fondos Oscuros** | `#202020` | ⬛ |
| **Fondos Claros** | `#F2F2F2` | ⬜ |
| **Texto Contraste** | `#FFFFFF` | ⬜ |

### 🔤 Tipografía
- **Fuente Principal:** `Inter`
- **Jerarquía:**
  - *Títulos:* 24px - 32px (Bold)
  - *Subtítulos:* 14px (Light)
  - *Texto Normal:* 14px - 16px (Regular) / 24px (Medium - Énfasis)
